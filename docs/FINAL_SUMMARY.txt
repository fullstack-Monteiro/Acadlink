🐛 TROUBLESHOOTING RÁPIDO
═══════════════════════════════════════════════════════════════════════════

  Backend não inicia?
  → Verificar Python: python --version
  → Reinstalar: pip install -r requirements/base.txt

  Frontend não inicia?
  → Verificar Node: node --version
  → Reinstalar: npm install

  Porta em uso?
  → Backend: python manage.py runserver 8001
  → Frontend: npm run dev -- --port 5173

  Mais ajuda?
  → Leia FINAL_SETUP_GUIDE.md
