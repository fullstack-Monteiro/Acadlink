# 🚀 COMECE AQUI - AcadLink

## ⚡ 2 Minutos para Começar (Rápido)

### Passo 1: Abrir 2 Terminais

**Terminal 1:**
```bash
cd backend
```

**Terminal 2:**
```bash
cd acadlink
```

---

### Passo 2: Executar Scripts Rápidos

**Terminal 1 (Backend - Rápido):**

Windows (PowerShell):
```powershell
.\run-quick.ps1
```

Windows (CMD):
```cmd
run-quick.bat
```

Linux/Mac:
```bash
chmod +x run-quick.sh && ./run-quick.sh
```

**Terminal 2 (Frontend):**

Windows (PowerShell/CMD):
```bash
npm install && npm run dev
```

Linux/Mac:
```bash
npm install && npm run dev
```

---

## 🐛 Problemas?

### Backend não inicia
```bash
# Verificar Python
python --version

# Reinstalar dependências (Rápido)
pip install -r requirements/dev-minimal.txt

# Ou (Completo)
pip install -r requirements/base.txt
```

### Frontend não inicia
```bash
# Verificar Node
node --version

# Reinstalar dependências
npm install
```

### Porta em uso
```bash
# Backend em outra porta
python manage.py runserver 8001

# Frontend em outra porta
npm run dev -- --port 5173
```
