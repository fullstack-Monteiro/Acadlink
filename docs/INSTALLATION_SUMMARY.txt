📋 ARQUIVOS DE REQUIREMENTS
═══════════════════════════════════════════════════════════════════════════

  requirements/dev-minimal.txt
  ├─ Django 4.2.11
  ├─ Django REST Framework 3.14.0
  ├─ Django CORS Headers 4.3.1
  ├─ PostgreSQL Driver
  ├─ JWT Authentication
  ├─ Python Decouple
  └─ Pillow (Imagens)
  
  Tamanho: 50MB | Tempo: 1 minuto

  ─────────────────────────────────────────────────────────────────────

  requirements/base.txt
  ├─ Tudo do dev-minimal +
  ├─ Channels (WebSockets)
  ├─ Daphne (ASGI)
  ├─ Celery (Async)
  └─ Redis
  
  Tamanho: 150MB | Tempo: 3 minutos

  ─────────────────────────────────────────────────────────────────────

  requirements/heavy.txt
  ├─ Tudo do base +
  ├─ FFmpeg (Video)
  ├─ OpenCV (Visão)
  ├─ AWS S3
  ├─ Sentry (Monitoring)
  ├─ Testing (Pytest)
  └─ Documentação (Swagger)
  
  Tamanho: 500MB | Tempo: 10 minutos
